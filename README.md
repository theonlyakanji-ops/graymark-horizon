# 🌅 GRAYMARK HORIZON — Degree & Future Career Evolution Platform

> An interactive AI application designed to help students, graduates, and professionals discover how traditional academic courses & degrees (Law, Accounting, Medicine, CS, Civil Engineering, Design, etc.) are evolving in the age of AI and automation.

## 🌟 Key Features

1. **Open-Ended Degree Search**: Type any course or field of study for instant AI disruption parsing.
2. **5-Year Disruption Radar**: Rating AI Impact %, Routine Tasks Automated %, and Human Advantage Index.
3. **Displaced vs Emerging Hybrid Roles**: Maps traditional majors to brand-new 2028-2030 job titles (e.g., Legal Tech Architect, AI Bio-Informatics Specialist, Financial AI Auditor).
4. **Step-by-Step Skill Bridge Roadmap**: Actionable 90-day & 1-year milestones for future-proofing your degree.
5. **Future Scenario Simulator**: Simulate Conservative, Moderate, or Accelerated AI automation scenarios.
6. **1-Click PDF Blueprint Export**: Export formatted PDF career evolution blueprints.

## 🚀 Setup & Execution

```bash
# 1. Install dependencies

# 2. Run local dev server
npm run dev
```
